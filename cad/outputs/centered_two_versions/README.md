# Centered Cirque enclosure — two versions

Both versions are **47 × 50 × 13.7 mm**, use four M2 screws with M2×4 heat-set inserts, retain the shared central FFC/AWG30 routing path, and place the 40 mm Cirque at the exact X/Y center of the enclosure.

## Version 1 — rounded bezel

Files beginning `centered_rounded_bezel_` use a **Ø37.8 mm opening**. The approximately 1.35 mm supporting rim is more durable and forgiving of printer tolerances. The exterior top perimeter has a 1.8 mm radius.

## Version 2 — near-borderless

Files beginning `centered_borderless_` use a **Ø38.8 mm opening** and a **Ø40.5 × 0.50 mm flush seat**. Only about 0.85 mm of printed retaining rim remains visible. This looks cleaner but is more sensitive to print accuracy and rough handling.

## Printing and fit

Use PETG if possible, 0.20 mm layers, four perimeters, and 25–35% infill. Test-print the sensor-opening region before printing the complete borderless top. The delivered Cirque overlay thickness determines perfect flushness; adjust the 0.50 mm recess by roughly ±0.15 mm if your measured part requires it.

Print only one bottom: the two bottom files are geometrically equivalent and are duplicated so each version has a complete matching file set.
